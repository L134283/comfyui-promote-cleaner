# Prompt Cleaner (提示词清洁)

把从 Danbooru 等站点复制来的「老式下划线标签」清洗成 **Anima Base** 可直接食用的提示词：逗号+空格分隔、括号转义为字面量、去重、清理残留分隔符、黑名单过滤。

纯文本进、文本出。可以同时接**多路文本**，全部按顺序拼接后一起清洁。清洗结果会直接显示在节点上（无需另接预览节点）。

## 输入

| 输入 | 默认 | 说明 |
| --- | --- | --- |
| `text_in` | 未连接 | **常驻可见的 STRING 连线口**。上游来的提示词会被清洁 |
| `extra_texts` | 1 个空闲口 | **额外文本口**：连上最后一个会自动再补一个（最多 10 个），也可点「＋ 文本输入口」手动加 |
| `text` | 空 | 原始标签，可直接打字。支持逗号分隔、一行一个标签、或两者混合 |
| `bracket_policy` | 仅转义圆括号 | 括号转义策略（**已收进设置窗口**） |
| `keep_weights` | 开 | 保留显式权重语法 `(tag:1.2)`（**已收进设置窗口**） |
| `underscore_to_space` | 开 | `_` 转空格（**已收进设置窗口**） |
| `dedupe` | 开 | 按标签去重（忽略大小写与首尾空格）（**已收进设置窗口**） |
| `strip_blacklist` | 开 | 启用黑名单过滤（**已收进设置窗口**） |
| `lowercase` | 关 | 输出标签全部转小写（**已收进设置窗口**） |
| `separator` | 逗号 + 空格 | 标签连接符，可选「逗号 + 空格」/「仅逗号」（**已收进设置窗口**） |
| `normalize_fullwidth` | 开 | 全角标点/全角空格转半角（**已收进设置窗口**） |
| `blacklist` | 内置默认规则 | 黑名单规则，可随意增删（**已收进设置窗口**） |

> 「已收进设置窗口」= 控件依然存在（工作流 JSON、序列化、后端取值全都不变），只是不画在节点上，统一在 **「⚙ 清洁设置」** 弹窗里编辑。弹窗里点「保存」才生效，「取消」不会改动任何值。

## 输出

| 输出 | 说明 |
| --- | --- |
| `cleaned_text` | 清洗后的单行提示词，可直接接到 CLIP Text Encode |

## 示例

| 输入 | 输出 |
| --- | --- |
| `drawing_bow` | `drawing bow` |
| `sunna (zenless zone zero)` | `sunna \(zenless zone zero\)` |
| `sunna_(zenless_zone_zero)` | `sunna \(zenless zone zero\)` |
| `(best_quality:1.3)` | `(best quality:1.3)` |
| `masterpiece, best_quality, 1girl, tagme, year 2024` | `masterpiece, best quality, 1girl` |

## 注意

- **裸括号会被转义**：`(masterpiece)` → `\(masterpiece\)`。因为 ComfyUI 会把任何 `(...)` 当成 ×1.1 的强调并吃掉括号，而 `sunna (zenless zone zero)` 这种角色系列名必须保留括号；两者无法区分，所以只保留带 `:数字` 的显式权重。要强调请写 `(tag:1.15)`。
- **权重会被保留**：`(masterpiece:1.2)`、`((masterpiece:1.2))` 原样通过，交给 ComfyUI 解析。
- **重跑安全**：清洗结果再次输入结果不变（幂等），可以串联多个清洁节点。
- 未闭合的 `(`、多余的 `)` 都会被安全忽略，不会报错或卡住。

## 多路文本输入

`text_in`、额外口、`text` 文本框**不是二选一**：接上几个就用几个。

| `text_in` | 额外口 | `text` | 实际清洁的内容 |
| --- | --- | --- | --- |
| 未连接 | 无 | `1girl, solo` | `1girl, solo` |
| `sunna_(zenless_zone_zero)` | 无 | 空 | `sunna \(zenless zone zero\)` |
| `sunna_(zenless_zone_zero)` | `1_girl` | 空 | `sunna \(zenless zone zero\), 1 girl` |
| `sunna_(zenless_zone_zero)` | `1_girl` | `best_quality` | `sunna \(zenless zone zero\), 1 girl, best quality` |
| `tagme`（黑名单开） | `watermark` | `logo` | 空（三个来源都会被黑名单过滤） |

- **顺序**（固定）：`text in` → 额外口（按槽位序号 `text_in_2`、`text_in_3` …）→ 文本框
- **合并后统一清洁**：去重、黑名单、括号转义都作用在合并后的整份文本上，所以跨来源的重复标签也会被去掉
- **加口**：连上最后一个空闲口会自动再补一个；也可以点节点上的「＋ 文本输入口」，或在设置窗口里点「＋ 添加」
- **删口**：在设置窗口的「文本输入口」区块里逐个移除（已连线的口必须先断开）
- 文本框默认是空的（示例放在占位提示里），所以只连线不填框时不会混入无关内容

> 文本框本身也是可连线的 widget（鼠标悬停左边缘会出现连接点）；`text_in` 只是为了让它一直可见。

## 设置窗口

节点上只留下两个按钮和一行设置摘要：

| 元素 | 作用 |
| --- | --- |
| `＋ 文本输入口` | 再补一个额外文本口 |
| `⚙ 清洁设置` | 打开设置弹窗（也可以右键节点选同名菜单项） |
| 设置摘要 | 一行显示当前开了哪些开关、括号策略与分隔符 |

弹窗分三个区块：**文本输入口**（增删插槽）、**清洁选项**（6 个开关 + 2 个下拉）、**黑名单**（多行编辑框）。
点「保存」生效，「取消」不改任何值，「恢复默认」恢复成内置默认值。
